### 파트 분류
| 구분 | 해당 PART | 미팅에서 설명할 핵심 |
| --- | :---: | --- |
| **업무의 기본 구조** | 1~4 | 누가 접근하고, 데이터를 어떻게 연결하며, 시스템끼리 어떤 규칙으로 통신하고, 상태를 어떻게 변경할지 정리 |
| **실패·충돌·보안 대응** | 5~7 | 동시 주문과 부분 실패를 어떻게 처리하고, 데이터를 어떻게 복구하며, 개인정보를 어떻게 보호할지 정리 |
| **서비스 운영 기준** | 8~10 | 주문이 몰리거나 장애가 발생했을 때의 대응과 배포·롤백 기준을 정리 |
| **검증과 범위 확정** | 11~13 | 구현 결과를 무엇으로 검증하고, 이번 프로젝트에 어디까지 포함하며, 미결정 사항을 어떻게 확정할지 정리 |

| 5 | **사용하는 데이터** | 조회·참조하는 데이터, 생성·변경하는 데이터, 데이터 간 연결 관계 |
