# B마트 공통 규칙 연결 대시보드

5개 도메인과 PART 1~12의 공통 규칙을 연결해서 확인하는 팀용 설계 대시보드입니다.

## 대시보드 실행
- 저장소 루트의 `index.html`을 브라우저에서 열면 됩니다.
- GitHub Pages: 저장소의 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**, `main`, `/(root)`를 선택하고 **Save**합니다.
- Pages를 활성화하면 예상 주소는 **https://whdrms971.github.io/bmart-study/** 입니다. 실제 활성화 여부는 **Settings → Pages**에서 확인하세요.

## 현재 제공 기능
- 전체 개요
- 도메인 × PART 연결 매트릭스
- 공통 규칙 58개 조회
- 팀 미정 정책 30건 조회·로컬 편집
- 구현 책임 및 후속 작업

## 공동 편집에 대한 중요한 안내
현재 `index.html`의 정책 변경 사항은 **개인 브라우저의 localStorage**에만 저장됩니다. GitHub Pages로 배포해도 팀원 사이에 자동 공유되지 않습니다. 목차 편집, 공동 본문 편집, 담당자/완료 체크, 동시 저장, 로그인은 아직 구현되지 않았습니다.

여러 팀원의 변경 사항을 동기화하려면 별도 인증 및 데이터베이스(예: Supabase)를 연결하고 서버 측 접근 권한을 검증해야 합니다. 공개 저장소에 개인정보·비밀키·실제 서비스 인증 정보를 저장하지 마세요.

## 내용 업데이트
코드가 수정되면 `main` 브랜치에 커밋·푸시하고 Pages 배포 결과를 확인하세요.
